# รูปภาพ QR Code

ใส่ครบทั้ง 4 ไฟล์แล้ว และ `index.html` (สไลด์ที่ 4, `.qr-grid`) เชื่อมเป็น `<img>` ไว้ครบทุกช่อง
หากต้องเปลี่ยนรูป ให้อัปโหลดไฟล์ทับชื่อเดิมตามตารางด้านล่าง (ไม่ต้องแก้ `index.html`)

| ไฟล์ | ใช้กับ |
|---|---|
| `qr-sheet.png` | QR ลิงก์ Google Sheet ไอเดียแคมเปญ |
| `qr-web-visual.png` | QR ลิงก์เว็บ Visual-Driven |
| `qr-dashboard.png` | QR ลิงก์เว็บ Data Dashboard |
| `qr-datachart.png` | QR ลิงก์ Data Chart Dashboard — สรุปผล KPI สำหรับนำเสนอทีมบริหาร |

แนะนำขนาดรูป: สี่เหลี่ยมจัตุรัส อย่างน้อย 400×400px พื้นหลังขาว (สแกนง่ายบนพื้นเข้มของสไลด์)
